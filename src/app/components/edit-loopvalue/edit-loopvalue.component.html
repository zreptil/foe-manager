Forge-Punkte


Forge-Punkte, die in der wiederkehrenden Quest ausgegeben werden müssen. Wenn hier ein Wert eingegeben wird, der grösser als 0 ist, dann gibt es bei der Eingabe des Eigenanteils in den legendären Gebäuden einen Button, der so aussieht: Wenn dieser angeklickt wird, dann wird der hier eingegebene Wert zum Eigenanteil dazu gezählt.
